# Stop asking a model to copy source evidence

An exact quotation check rejected two retained ADR answers and consumed the existing repair without changing the reasoning. The correct boundary is code-owned source evidence, not more quotation instructions.

The model selects eligible refs and explains implementation. Code inserts exact source snapshots with source revision hashes and mandatory concept links. Hash checks prove identity, never relevance. Every source-linked ADR raises an explicit human support-review finding at the existing architecture review, with no extra model call. Plain Accept or hands-free continuation does not close it. A finding disposition is bound to the complete ADR and all source snapshots; changed evidence needs review again.

Legacy records stay readable without invented evidence or founder approval. Source integrity is checked at partial resume, assembly and handoff export. The source quotation is labeled separately from system architecture reasoning.
